## 🚀 Featured Projects

### 🎙️ Voicebot — ASR · Intent · TTS

A conversational voice bot that transcribes speech with Whisper, classifies user intent using DistilBERT, generates a contextual response, and returns spoken audio — served via FastAPI.

| Aspect | Detail |
|---|---|
| **Stack** | Python, FastAPI, Whisper, DistilBERT, gTTS |
| **Scale** | End-to-end speech-in → speech-out pipeline |
| **Performance** | Low-latency ASR → NLU → TTS chain |
| **Security** | API-isolated inference endpoints |
| **Impact** | Demonstrates full voice-interface AI pipeline design |
| **Repository** | [voicebot-asr-intent-tts](https://github.com/darshan-s-44/voicebot-asr-intent-tts) |

This project integrates three distinct AI subsystems — speech recognition, language understanding, and speech synthesis — into a single cohesive service, showcasing practical multi-model orchestration.

### 🤖 AutoStream AI Agent — RAG · LangGraph

A conversational AI agent built for the AutoStream SaaS product, combining intent detection, retrieval-augmented generation over a knowledge base, and automated lead capture.

| Aspect | Detail |
|---|---|
| **Stack** | Python, LangGraph, RAG, Jupyter |
| **Scale** | Multi-turn conversational agent with knowledge retrieval |
| **Performance** | Context-aware responses grounded in retrieved documents |
| **Security** | Scoped knowledge-base access per query |
| **Impact** | Automates SaaS customer engagement and lead qualification |
| **Repository** | [autostream-ai-agent](https://github.com/darshan-s-44/autostream-ai-agent) |

Built around LangGraph's stateful agent orchestration, this project explores how graph-based agent design improves reliability over simple prompt chaining.

### 🧠 Brain Tumor Classification — ASPP-Integrated CNN

A hybrid deep learning model combining Atrous Spatial Pyramid Pooling (ASPP) with CNNs to improve MRI-based brain tumor segmentation and classification accuracy. Peer-reviewed and accepted at an IEEE International Conference.

| Aspect | Detail |
|---|---|
| **Stack** | Python, TensorFlow/PyTorch, Jupyter Notebook |
| **Scale** | Trained on BraTS-style MRI datasets |
| **Performance** | Improved segmentation accuracy via multi-scale context (ASPP) |
| **Impact** | Contributes toward automated, accurate tumor detection in medical imaging |
| **Repository** | [brain-tumor-classification-mri](https://github.com/darshan-s-44/brain-tumor-classification-mri) |

Applies atrous convolutions to capture multi-scale spatial context — a technique borrowed from semantic segmentation research — to a medical imaging classification task.
